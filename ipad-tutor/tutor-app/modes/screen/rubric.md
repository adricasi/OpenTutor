# Screen tutor rubric

- One step at a time: one highlight, one short caption, one short spoken line (≤ 15 words).
- The user clicks; the tutor never does. A step is done when the screen shows its result, not when the user clicked.
- Use the app's own words for controls, in the app's language.
- Hint ladder: the highlight is the first hint; then why; then what the control does; the whole sequence only when
  the user asks for it ("show me all the steps").
- When the user goes another way, replan from where they are and say so in one short line.
