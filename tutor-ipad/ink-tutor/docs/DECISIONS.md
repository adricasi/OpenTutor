# Decisions log

Format: decision — why — alternatives rejected — date. Append-only: a later entry amends an earlier one instead of rewriting it. "Non-negotiable N" refers to the list in `ARCHITECTURE.md` §0.

1. **Web app only; no native iOS/macOS.** No Apple developer account is needed. iPad uses Safari with Apple Pencil (pointer events give pressure/tilt). Rejected: SwiftUI + PencilKit (better latency, needs an account). 2026-10-23
2. **Fully local by default; cloud (Anthropic/OpenAI) only as an explicit per-session toggle for tier 2.** Recognition never leaves the Mac. Rejected: MyScript iink (best online recognition, but cloud-only, metered, diagrams REST-only). 2026-10-23
3. **Ink stays ink.** The tutor never modifies, snaps or typesets user strokes; it annotates on separate layers in its own hand. Rejected: live typeset "twin" pane; converting sketches to clean shapes as the primary view; inline tutor text between lines. 2026-10-23
4. **Two-tier pipeline.** Tier 1 instant local recognition (mathnote-ocr for math strokes; Qwen3.5-4B for text/CJK; Chandra 2 for photos). Tier 2 Qwen3.6-35B-A3B MLX for tutoring. Rejected: one dense 27B model doing everything (too slow for real-time feel on M3 Pro); frontier-only pipeline (not local). 2026-10-23
5. **Deterministic checkers run before the LLM** and the LLM may not contradict them (it may ask instead). 2026-10-23
6. **Canvas: tldraw SDK** for its editor API (programmatic shapes/annotations, Mermaid → native shapes, export). Caveat: since SDK 4.0 it is source-available with a license key required in production (free hobby key with watermark; dev mode needs no key). **Fallback: Excalidraw (MIT)** if the license becomes a problem; backend is agnostic (strokes + PNG). Hand-rolled canvas (perfect-freehand) acceptable if diagrams become secondary. 2026-10-23
7. **Recordings as fixtures.** Timestamped stroke logs + checkpoint snapshots + `truth`/`expect` fields recorded with real handwriting; truth is drafted automatically from the snapshots and confirmed by a person. Rejected: screen recordings as test data (no coordinates/timing, lossy). 2026-10-24
8. **Voice channel in the final product**, local stack (Silero VAD, Parakeet TDT, Kokoro/Qwen3-TTS), feeding the same session agent; short unprompted speech, barge-in, speech controls the hint ladder. Cloud realtime speech only when the cloud toggle is on. 2026-10-24
9. **Demo scope:** maths + system design + one language on one canvas; accounting T-accounts as a cheap fourth. 2026-10-23
10. **Local tier-2 model is a config var + UI picker, not a hard choice.** `LOCAL_MODEL` selects a manifest entry; runtime swaps the model server with a memory check; Qwen3.6-35B-A3B default, Gemma 4 26B-A4B and Qwen3.8-27B registered. Pick the default after `make judge` on the real recordings. 2026-10-24
11. **Fixture recording over a Cloudflare quick tunnel** (in the separate stroke-recorder tool) so an iPad/iPhone can record without being on the Mac's network; token-gated, auto-sync to the Mac because tunnel URLs (and thus browser storage) change per run. Tooling only — the app itself pairs over the LAN (ARCHITECTURE §8; amended by #26). Rejected: named tunnels (need a Cloudflare account + domain), ngrok (account, limits). 2026-10-24
12. **Repo-local tooling, Python-packaged where possible.** Tools come from pip packages rather than system installs (e.g. ffmpeg via `static-ffmpeg`, not Homebrew); uv/HF/Playwright caches and binaries live inside the repo base folder. 2026-10-24
13. **The app lives in `tutor-app/` (sibling of this spec kit)**, laid out as `apps/web`, `apps/server`, `packages/protocol`, `modes/`; it reads fixtures, the model manifest and weights from `../ink-tutor`, so the app and its design kit stay separate. 2026-10-24
14. **Ground truth goes in sidecars** `fixtures/annotations/<recording>.json` (mode/problem corrections, checkpoints with `truth`/`expect`, `draftedBy: "auto"` for drafted fields, `confirmed: false` until a person checks them). The raw recordings stay byte-for-byte as recorded. The first real recordings had no checkpoints and the consulting one was saved as `math`. 2026-10-24
15. **Canvas: hand-rolled (2D canvas for ink + SVG tutor layer + HTML popovers), not tldraw** — DECISIONS #6's allowed fallback. Why: the stroke recorder already proved this input path on a real iPad (incl. the quick-Pencil-stroke fix); tldraw 4 needs a license key off localhost, and the iPad reaches the Mac over the network; the tutor layer is custom shapes either way and the user's ink is never edited, so tldraw's editing tools aren't used. Revisit for "show reference design" (Mermaid) if needed. 2026-10-24
16. **The line being written is graded only once it settles** (2.5 s pen-up idle, or the pen starts another line). Lines that are done are checked right away, and a line's marks are retracted when it changes. Why: the real recordings have 40 pauses > 700 ms inside a solution (thinking at "x³ dx ="), so checking at the 700 ms debounce would ✗ half-written lines. 2026-10-24
17. **Tier 1 = geometry first, then a small VLM per region.** Strokes are grouped into regions (anisotropic gaps, same-row rule, fraction bars); long divisions are found from their "└" bracket and their parts assigned by position; each changed region is read by Qwen3.5-4B (a labelled sheet for divisions), confidence from token probabilities. mathnote-ocr misread the handwritten 1/5/0 in the recordings (kept as an optional extra for later fine-tuning). The 300 ms tier-1 target is not met (2–3.5 s per line); reads start at the debounce and overlap the settle time, so the first mark still lands < 4 s. 2026-10-24
18. **Tier-2 memory policy: full only with 6 GiB headroom, else expert offload, else refuse; watchdog downgrades.** Measured on the reference Mac (M3 Pro, 36 GB; docs/MODELS.md). `LOCAL_MODEL` default stays Qwen3.6-35B-A3B (non-negotiable 3); on this Mac it usually runs offloaded (slower tutor text, same checker marks). Gemma 4 runs fully resident when ~22 GiB are free. Whether to make Gemma the default is to be decided after more fixtures are judged (see #25). 2026-10-24
19. **Checkers own the marks on lines they can decide;** the tutor adds speech, explanations and hint wording there, and marks only lines no checker decided ("?" rather than "✗" in maths). Hint level 3 for checkable lines is the checker's exact corrected step as ghost ink; levels 1–2 are the tutor's wording (checker wording if no tutor); level 4 only on an explicit request. Every feedback event about a line is retracted when the line changes or is erased. 2026-10-24
20. **Kokoro uses the system espeak-ng (Homebrew)** for out-of-lexicon English words and non-English voices. This is the one system dependency; everything else stays repo-local (#12). Without it the engine falls back to English-only with unknown words skipped. 2026-10-24
21. **Voice answers are spoken while they stream** and the student's voice pauses the tier-2 review (it shares the model server's GPU); the review resumes after the turn. 2026-10-24
22. **HTTPS for the iPad (needed for the microphone) through an opt-in Cloudflare quick tunnel (`make pair`)**, token-gated like the recorder's tunnel (#11); LAN http stays the default and needs no token. Chosen over mkcert (no certificate to install on the iPad). Trade-off: through the tunnel, ink and audio pass Cloudflare's edge (TLS ends there), while non-negotiable 7 says the iPad uses Safari over the LAN — kept as an opt-in so the LAN path is unchanged. 2026-10-24
23. **"Keep page history after wipe" is a per-session toggle, off by default.** When on, wiped lines (confirmed reading + checker verdict, capped at 12 lines / 1500 chars) are given to the tutor as prior work, never marked. Turning it off clears it. 2026-10-24
24. **Sudoku: rule conflicts (row/column/box, miscopied givens) are ✗ unprompted; a digit that breaks no rule but contradicts the unique solution is not crossed unprompted** — it is named in that cell's hints and next-move hints point at it first (`solution_check = "on_request"` in `modes/sudoku/config.toml`; `"unprompted"` crosses it). Why: a ✗ there gives away the solution, against the hint ladder. Accounting: debits = credits per entry, totals and T-account balances are checker marks; the tutor may only ask (?) whether the right account is used. Both modes ship with synthetic fixtures (generated pen strokes, `ink-tutor/tools/synthetic/`) until real ones are recorded. 2026-10-24
25. **Gemma 4 26B-A4B is the default local tutor** (amends non-negotiable 3, which named Qwen3.6). It runs fully resident on the reference Mac (16 GB; judge 100 % on maths, 1/1 consulting) where Qwen3.6 usually had to run expert-offloaded (~6 s to first token). Qwen3.6 and Qwen3.8 stay selectable. 2026-10-24
26. **The iPad reaches the Mac through the Cloudflare tunnel (`make pair`) by default**, so it works on networks you don't control (venue/guest Wi-Fi, no LAN pairing), and Safari needs HTTPS for the microphone anyway. Supersedes the opt-in framing of #22; LAN http still works where the network allows it. 2026-10-24
27. **Voice stays local:** spoken answers are not sent to a cloud provider to win latency. 2026-10-24
28. **Spoken questions stay with the tier-2 tutor (Gemma), not the resident tier-1 model.** Tried 2026-10-24: Qwen3.5-4B answering `converse` from the same prompt and checker verdicts was not faster in practice (first sentence 1.4–1.7 s vs Gemma's 1.0 s warm) and broke the hint ladder ("the antiderivative of x³ is x⁴/4" unprompted) and echoed a Spanish question back. Voice latency work goes into keeping the tier-2 model warm and the prompt prefix cached instead. 2026-10-24
29. **Speculative prefill for spoken questions.** When the VAD hears the student start talking, the agent sends the converse prompt (page context, empty question, 1 token) to the local tier-2 model, so its prefix cache and paged-in weights are ready when the transcript arrives ~0.5 s after they stop; only their words are prefilled then. Local tutor only (a cloud call would cost money for nothing). 2026-10-24
30. **Screen tutor mode added** (`docs/SCREEN-TUTOR.md`): Mac only; walks the user through software tasks over any app with highlights, arrows and spoken steps, and detects step completion. The native overlay helper (`apps/overlay`, Swift/AppKit, ad-hoc signed, run locally) is the one exception to web-only (non-negotiable 7; still no App Store, no iOS native, no developer account). It points, it never acts (non-negotiable 10; `ALLOW_AUTOMATION=false`). Rejected: a browser-only overlay (can't draw over other apps or read their accessibility tree); automation-first (does the task instead of teaching it). 2026-10-24
31. **The screen-tutor design follows the app as built:** paths are `tutor-app/apps/overlay`, server modules `screen/`, `ax/`, `guide/` under `inktutor_server/`, recipes `tutor-app/modes/apps/<app>.md`, plus a `modes/screen/` mode folder and `tutor/prompts/screen.md` (#13); protocol in the `models.py` style (`_M`, `BBox`, dotted `type` literals, server payloads wrapped like `FeedbackMsg`), JPEG as `jpeg_b64` not `bytes` (JSON wire, like `pcm16_b64`), coordinates in global display points (`ScreenFrame.origin`, `AXSnapshot.pointer`), `OverlayEvent.id`/`state`, `Target.source` optional until located; wire `guide.status`, `guide.goal` / `guide.control` / `session.update {voice}` for the phantom icon, caption + `voice.audio` for spoken steps, `screen.config` (blocklist sent to the helper, which skips those windows before capture); the blocklist is the `SCREEN_BLOCKLIST` env setting; own endpoint `/ws/screen/{id}`, localhost only, so screen data never goes through the tunnel (#26); the `Tutor` interface gains `plan`/`locate` (streamed JSON lines, same providers, `_ask_tutor` fallback) instead of a new client; next/back/repeat/stop join `voice/session.py`'s `COMMANDS`; voice stays local even with the cloud toggle (#27); Gemma 4 plans and locates (#25). 2026-10-24
