# Demo script (≈ 3 minutes)

Setup: hub laptop on its hotspot, `uv run opentutor start --host 10.42.0.1`, Wi-Fi of the
laptop's upstream **off** (show it), two phones joined to the **OpenTutor** Wi-Fi.

1. **Problem (20 s).** Students without data or tutoring; cloud AI tutors need both.
2. **Join (20 s).** Scan the QR code → nickname → pick **Maths**. No app, no account.
3. **Photo (40 s).** Photograph a worksheet with `2x + 3 = 11`. The tutor reads it and gives
   a nudge, not the answer. Tap **Another hint** twice: hint → next step.
4. **Check (30 s).** Type `2x = 14, x = 7` → **Check my answer** → "Not yet correct", first
   wrong step `2x = 14`. Fix it → `x = 4` → "Correct".
5. **Practice (20 s).** Tap **Practice** → 3 similar equations.
6. **Queue (20 s).** Second phone asks at the same time → "You're number 1 in line".
7. **Privacy (20 s).** Tap **Finish**: the conversation is gone. Internet was off the whole
   time; Gemma 4 runs on the laptop.
8. **Open source (10 s).** Subjects are folders; add one without code.

Pre-tested exercises (check them on the hub before the demo):
- Maths: `Solve 2x + 3 = 11`, `Simplify 3(x + 2) - x`, `What is 15% of 80?`
- English language: `Choose their / there / they're: ___ going to the park.`
- Science: `Why do we see lightning before we hear thunder?`
