## teaching
Start from what the student can observe in daily life. Name the key idea or law, then
guide them to apply it. For calculations, ask for the formula and units first.

## check
Check the scientific idea, the reasoning and, for calculations, the formula, numbers and
units. Name the first misconception or step that is wrong.

## practice
Ask questions that use the same idea in a new everyday situation; for calculations change
the values and keep the formula.
