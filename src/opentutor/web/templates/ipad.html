For the teacher

The iPad tutor is a separate service on a Mac. To connect it:

  1. On the Mac, start it: cd ipad-tutor/tutor-app && make ipad
  2. Start this hub with OPENTUTOR_IPAD_URL=<the link it prints> (or set ipad_url in opentutor.toml).

The iPad’s microphone needs the HTTPS link that make ipad prints. See the README, “iPad handwriting tutor”.
